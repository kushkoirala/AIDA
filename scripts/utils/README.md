# Utility Scripts

Shell scripts for running various components of the AIDA project.

## Scripts

- **run_cessna172_viewer.sh** - Start Cessna 172 telemetry viewer
- **stop_cessna172_viewer.sh** - Stop Cessna 172 telemetry viewer
- **run_all.sh** - Run all pipeline components
- **run_all_cruise.sh** - Run cruise flight pipeline
- **run_full_bc_pipeline.sh** - Run full behavior cloning pipeline

## Usage

Scripts are meant to be run from the AIDA root directory:
```bash
cd /home/AIDA
./scripts/utils/run_cessna172_viewer.sh
```
