# Assets

This directory contains project assets including 3D models, research papers, and other resources.

## Directory Structure

- **aircraft/** - 3D models and CAD files for aircraft
  - Cessna 172 (GLTF and binary formats)
  - Udaan custom aircraft (GLTF, STL, STEP formats)

- **papers/** - Research papers and references
  - Imitation learning for neural network autopilot paper

## File Formats

- `.gltf` - GL Transmission Format (3D models)
- `.bin` - Binary data for GLTF models
- `.stl` - Stereolithography CAD file
- `.stp` - STEP 3D CAD file format
- `.pdf` - Research papers
